# 🌐 CodeAlpha Internship – Task 3

## 📚 Web Scraping using Python

I completed this project as part of my **CodeAlpha Data Analytics Internship**. 🚀

In this task, I used Python to collect book information from a website. I collected the **book name, price, and rating** and stored the data in a table.

After scraping the data, I cleaned it and did some basic analysis. I also created a few charts to understand the data better. 📊

## 🛠️ Tools I Used

- 🐍 Python
- 🌐 Requests
- 🥣 BeautifulSoup
- 🐼 Pandas
- 📊 Matplotlib
- 💻 Google Colab

## 🔎 What I Worked On

- 🌐 Scraped book details from the website
- 📚 Collected book names
- 💰 Collected book prices
- ⭐ Collected book ratings
- 🧹 Cleaned the data
- 🔍 Checked for missing values
- 📊 Created charts
- 💾 Saved the data in CSV format

## 📊 Charts I Created

- 💰 Book Prices
- ⭐ Books by Rating
- 💵 Top 5 Most Expensive Books

## 💡 What I Found

The most expensive book in the data was:

**Our Band Could Be Your Life: Scenes from the American Indie Underground, 1981-1991 – £57.25**

The cheapest book was:

**Starving Hearts (Triangular Trade Trilogy, #1) – £13.99**
