# 🖼️ Power BI Dashboard

This folder contains the screenshot of my **Power BI dashboard** that I created as part of my **CodeAlpha Data Analytics Internship**. 🚀

The dashboard is based on the **Supermarket Sales dataset**. I created different charts, cards, and filters to understand the sales data in a simple way. 📊

## 📌 Dashboard Includes

- 💰 Total Sales
- 📦 Total Quantity
- ⭐ Average Rating
- 🏙️ Sales by City
- 🛍️ Sales by Product Line
- 👥 Sales by Gender
- 💳 Sales by Payment Method
- 📅 Monthly Sales Trend
- 🎛️ Filters for Gender, City, and Payment
