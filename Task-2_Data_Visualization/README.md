# 📊 CodeAlpha Internship – Task 2

## 📈 Data Visualization using Power BI

This project is a part of my **CodeAlpha Data Analytics Internship**. 🚀

In this task, I created a **Power BI dashboard** using the Supermarket Sales Dataset. I used different charts and cards to understand sales, customers, products, and payment methods.
